# itis-2026-dataBase-atushkina
Название проекта: Absolute_Cinema - система управления кинотеатром.
Предметная область: Прокат фильмов, расписание сеансов, залы и продажа билетов.
Решаемая проблема: Автоматизирует учёт сеансов и продажу билетов. Исключает двойную продажу места, ускоряет поиск свободных мест и формирования расписания, обеспечивает целостность данных.
